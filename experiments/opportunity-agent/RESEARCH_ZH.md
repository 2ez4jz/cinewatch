# 第二行业筛选与商业判断

检查日期：2026-10-23，America/New_York。以下分为已经取得的证据、推断与尚未验证的商业条件；不把公开访问等同于允许任意自动采集。

## 两个候选

| 维度 | A：MTG精确版本卡牌 → 本地商家现金收购 | B：政府剩余小型电子设备 → 本地转售 |
| --- | --- | --- |
| 入口 | Scryfall正式API提供身份和每日参考行情；进货价另需授权货源或人工核验 | GCSurplus公开拍卖目录与拍卖详情 |

| 供需/价格变化 | 商家收购量与现金价变化、现货降价可观察，但必须精确匹配版本/语言/品相 | 新上架、临近截止、出价变化可观察；当前出价不等于最终购入成本 |
| 交易出口 | 401 Games、Face to Face的卡牌收购流程；最终接受和鉴定有条件 | 面向本地最终买家或事先确认的设备回收商；本次没有核验现金收购承诺 |
| 潜在收益 | 不知道。没有真实双边价格证据，不能估每周/每月收入 | 不知道。未建立型号、配置、状态一致的真实已成交对照 |
| 试验投入 | 先纸面0库存；再用CAD100以内做1笔，有便携交付可能 | 先纸面0库存；即便小件也要检测、取货及保管，实际资本依标的而变 |
| 执行成本 | 报价核验、鉴真、分拣、交付；小额运费和品相扣减会吞利润 | 取货、检测、配件、电池/锁定状态、退货、等候买家，工时更高 |
| 关键风险 | 错版/foil、假卡、品相折价、商家撤价、积分误当现金、收购数量不足 | 竞价抬升、as-is状态、未知故障、运输损坏、没有真实退出买家 |
| 本次决定 | **相对优先，仅做有证据门槛的小原型；商业可行性未通过** | **暂缓自动抓取和开发**；不是判定拍卖领域整体不可行 |

对当前偏好低投入、快速验证的目标，A的核验单位更小、可以先锁定潜在收购方。这个排序是执行成本推断，不是对卡牌市场有利可图的事实判断。若需要从零学习鉴真、分级，人工成本可能足以推翻排序。

## 已核实的来源

1. [Scryfall API](https://scryfall.com/docs/api)：正式提供程序访问，要求准确 User-Agent 和 Accept。真实请求成功返回3个精确版本，样本保留于 `evidence/scryfall-reference.json`。只保存身份/参考字段，没有复制卡图、卡面长文本或做图片再分发。
2. [Scryfall速率与缓存](https://scryfall.com/docs/api/rate-limits)：价格每日更新，24小时内重复请求没有新价格收益。实验缓存24小时、串行间隔600ms，遇429停止。
3. [Scryfall批量数据说明](https://scryfall.com/docs/api/bulk-data)：价格只适合趋势和一般估值，不足以直接作为销售系统价格；超过24小时需特别谨慎。参考价不进入本实验的现金退出计算。
4. [401 Games官方收购说明](https://store.401games.ca/pages/selling-to-us-guide)：提供现金支付方式，但公开收购价仅供参考、可能变动，最终金额依核验确定；品相、版本、数量都影响结果。积分不是现金。没有根据该页面推定获得其内部接口的自动采集权限。
5. [Face to Face官方收购说明](https://support.facetofacegames.com/en-US/articles/how-to-sell-cards-344162)：存在收购、品相审核与支付流程，提示交付时限和品相争议。这里证明“存在交易出口”，没有证明任意卡片都会按某个价格被收购。
6. [GCSurplus如何运作](https://gcsurplus.ca/mn-eng.cfm?snc=hgw&wbdisable=false)、[条款](https://gcsurplus.ca/mn-eng.cfm?snc=tc)：官方公开拍卖存在；[官方商品条款示例](https://gcsurplus-mirror.aws.tpsgc-pwgsc.cloud-nuage.canada.ca/mn-eng.cfm?fromsc=ach-shop&lci=&lcn=766635&lct=L&lotnf=1&pmtd=3&sanv=605269&sc=gcs&sf=ferm-clos&snc=wfsav&so=&srchtype=&str=1&tc=A&type=L&wbdisable=true)说明按现状/所在地销售。该条款示例来自检索，不将缓存商品当作当前可买标的。

## 为何不直接拿参考价做套利提醒

缺少以下任何一项，就不能说明能赚钱：可买的现货数量、实际含税含运进货成本、对同一精确商品的现金收购量/价、报价覆盖交付时间、品相/鉴真损失、人工和运输成本。

演示虚构价：买CAD20，现金退出CAD60；示例税2.60、交通4、人工5、损失准备3，得所得税前估算净额CAD25.40。这只是计算验证，没有这张报价单，更不是可买建议。

拍卖的反例也可以纸面验证：假设退出价200、最终出价110、示例税14.30、取货30、检测10、人工20、损失准备20，即使表面价差90，估算净额仍为负4.30。此处全部数字是假设，不是实际标的估价。

## 商业验证的判定方式

不能用“抓到了多少变化”替代验证。未来14天试验需记录：

| 记录 | 意义 |
| --- | --- |
| 合规可用报价的覆盖率、失败率、更新时间 | 判断是否能持续获得输入，而非人工补齐一次演示 |
| 满足完整成本门槛的独立事件数 | 去掉重复出现、错误品相和非现金退出后的线索频率 |
| 提醒时能否实际买到与提交现金收购 | 检查报价时效与库存/需求真假 |
| 实收净额、等待支付天数、占用资金 | 区分纸面利润和已实现结果 |
| 人工分钟数、退卡/扣价、未售出损失 | 防止以省略劳动和失败成本制造收益 |

建议纸面样本10–20个精确版本、至少两个双边报价来源；不先购买数据库订阅。14天出现≥3次独立可复核机会，再尝试1笔购入不超过CAD100的完整现金退出。只有实际净额和时薪达到自定门槛、且数据权限明确，才考虑定时任务或付费数据；否则停止该场景，保留通用小组件。

没有向任何商家询价、联系、提交buylist或下单。没有模拟成真实成交；本次无法证明连续真实机会发现或变现频率。
